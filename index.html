Infrastructure-grade. Max entropy for SSH, root/admin accounts, ERP, firewalls, routers, VPN gateways, Wi-Fi WPA3 and service accounts. Safe-ASCII only (no quotes, backslash, or spaces) so it works in config files, YAML, env vars and shell.

Your name is a memory hook only — it counts as 0 bits. Strength comes from the random core and random words.

PINs are short, so they only hold up where the system limits wrong tries (phone lock, ATM, SIM). Use 6+ digits when the service allows it.

Android-style pattern lock: 4–9 dots joined in order. Shoulder-surfing and smudge attacks make these weak — longer and twistier is better.

    Guidelines

    • Everyday accounts: 60+ bits
    • Admin/root/ERP: 128+ bits
    • SSH/service keys: 192+ bits
    • Never reuse — one leak sinks everything
    • Always enable 2FA/MFA on top
    • Rotate shared infra passwords on staff changes

    100% private. Random values come from crypto.getRandomValues(). Nothing is stored, logged or sent. The optional breach check sends only the first 5 chars of an SHA-1 hash (k-anonymity).
